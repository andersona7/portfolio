> A world-class, futuristic, AI-inspired developer portfolio designed with premium SaaS aesthetics. 

## 🚀 Overview

This is the personal portfolio repository of **Anderson A.**, a Computer Science Engineering student and aspiring Full Stack AI Engineer. Built to stand out to modern tech recruiters, the site features a deep dark-theme, glassmorphic UI, fluid cinematic animations, an interactive developer terminal, and a custom high-performance "AI Halo" magnetic cursor.

## ✨ Key Features

* **Premium SaaS Aesthetic:** Deep space dark theme with aurora gradient overlays and frosted glassmorphism UI cards.
* **Cinematic Animations:** Powered by GSAP and Lenis for buttery-smooth scrolling, parallax, and scroll-reveal effects.
* **Interactive Developer Terminal:** A functional mock CLI to explore skills and projects using commands like `whoami` and `projects`.
* **AI Magnetic Cursor:** A custom-built, highly performant trailing cursor that magnetically snaps to interactive UI elements.
* **Live GitHub Dashboard:** Asynchronously fetches and displays live repository stats and the latest public commit activity.
* **Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript for maximum performance and SEO optimization.

## 🛠️ Tech Stack

* **Core:** HTML5, CSS3, Vanilla JavaScript
* **Animations:** [GSAP (GreenSock)](https://greensock.com/gsap/)
* **Scroll Engine:** [Lenis Smooth Scroll](https://github.com/studio-freight/lenis)
* **Visual Effects:** [Particles.js](https://vincentgarreau.com/particles.js/)
* **Typography:** Inter & Space Grotesk (Google Fonts)
* **Icons:** FontAwesome
